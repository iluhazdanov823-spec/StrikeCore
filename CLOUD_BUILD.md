# StrikeCore — APK без Termux

1. Создай пустой репозиторий на GitHub.
2. Загрузи содержимое этого проекта в репозиторий.
3. Открой Actions.
4. Выбери `Build StrikeCore APK`.
5. Нажми `Run workflow`.
6. Дождись окончания сборки.
7. Открой готовый workflow.
8. В разделе Artifacts скачай `StrikeCore-Android-APK`.
9. В архиве будет APK.

На телефоне не нужны Termux, Ubuntu или Buildozer.
Сборка выполняется GitHub Actions на сервере.
